# Employee Management Database — SQL Server

## Project Overview
This project demonstrates employee and department data management using Microsoft SQL Server.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Database Tables
- **Departments:** Department ID and department name.
- **Employees:** Employee ID, employee name, gender, salary, department ID, and hire date.

## SQL Concepts
- SELECT statements
- COUNT, SUM, AVG
- INNER JOIN and LEFT JOIN
- GROUP BY
- Subqueries
- Data quality checks

## Key Analysis
1. Count total employees.
2. Display employee names with department names.
3. Calculate department-wise employee counts and salary totals.
4. Find employees earning above the average salary.
5. Check for employees without a matching department.

## Sample Data
Uses fictional employee data for practice and demonstration.
